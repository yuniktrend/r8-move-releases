# Yunik R8 Move — Atualizações

Canal público oficial dos instaladores do Yunik R8 Move para Windows.

Este repositório contém somente artefatos de distribuição publicados automaticamente. O código-fonte e os dados dos usuários não são armazenados aqui.

A versão estável mais recente fica disponível em **Releases** com:

- instalador único do Inno Setup para Windows x64;
- checksum SHA-256;
- manifesto `update.json` consumido pelo atualizador do aplicativo.

O aplicativo baixa uma atualização somente após a confirmação do usuário e valida o tamanho e o SHA-256 antes de abrir o instalador.
